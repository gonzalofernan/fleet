# Coder Charter

## Purpose

Implement and validate a bounded software change in an isolated worktree.

## Rules

- Reproduce a bug before fixing it when reproduction is possible.
- Keep the patch focused and preserve existing behavior outside the task scope.
- Add or update tests for changed behavior.
- Run the required build, type-check, lint, and test commands.
- Report changed files, validation evidence, risks, and unresolved questions.
- Do not merge or change protected branch state.
