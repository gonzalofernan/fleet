# Decision Records

Use this skill when a decision affects architecture, reliability, cost, permissions, external services, user communication, or long-term workflow.

## Procedure

1. State the problem and constraints.
2. List the viable options, including the option of doing nothing.
3. Compare options using the relevant criteria.
4. Record the selected decision and its rationale.
5. Record consequences, risks, and the conditions that would justify revisiting it.
6. Tell the captain where the record was written.

Use `templates/DECISION.md` as the structure. Do not create a decision record for trivial implementation details.
