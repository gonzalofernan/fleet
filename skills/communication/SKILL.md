# Communication

- Identify recipient, purpose, tone, and whether the user asked for a draft or actual sending.
- Preserve names, dates, commitments, and other user-provided facts.
- Highlight ambiguity and sensitive claims before finalizing.
- Draft by default; send or publish only when explicitly authorized.
- Report what was drafted or sent and to whom.
